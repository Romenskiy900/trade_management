=====================
Trade Management
=====================

Огляд
=====
Цей модуль реалізує базову систему управління торгівлею, яка включає:

- Облік надходження товарів
- Ведення продажів
- Інструменти для звітності
- Рольовий доступ користувачів

Функціональність
================
- Управління надходженням товарів (receipts)
- Облік руху товарів і продажів
- Рольова система доступу (Менеджер, Аналітик, Адмін)
- Друковані звіти по надходженнях
- Базові тести для основної логіки

Залежності
==========
Модуль залежить від:

- base
- product

Встановлення
============
1. Скопіюйте модуль у директорію addons вашого Odoo.
2. Оновіть список додатків (Apps).
3. Встановіть модуль через меню Applications.

Налаштування
============
Після встановлення призначте користувачам ролі:

- Менеджер: керування надходженнями та продажами
- Аналітик: перегляд звітів
- Адміністратор: повний доступ

Використання
===========
Перейдіть у відповідні меню:

- Закупівлі → Надходження
- Продажі → Замовлення
- Звіти → Звіти по торгівлі

Безпека
=======
Права доступу визначені у:

- security/ir.model.access.csv
- групи користувачів у XML файлах
